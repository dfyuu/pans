# CONTRIBUTING.md

Thank you for your interest in contributing to this project.

To keep the codebase consistent and maintainable, please follow the guidelines
described in this document when submitting code or making changes.

## Coding Conventions
- **Constants:** Use `UPPER_CASE`.
- **Class names:** Use `PascalCase`.
- **Non-static member function:** Use `camelCase`.
- **Static member funtion:** Use `PascalCase`.
- **Non-static member variables:** Use the `m_` prefix followed by `camelCase`.
- **Static member variables:** Use the `s_` prefix followed by `camelCase`.
- **Global functions:** Use `PascalCase`.
- **Function parameters:** Use `snake_case`.
- **Local variables:** Use `snake_case`.
